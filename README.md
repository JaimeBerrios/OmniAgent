# OmniAgent

Plataforma académica de atención omnicanal con automatización e inteligencia artificial.

## Tecnologías

- Vue.js
- FastAPI
- PostgreSQL
- n8n Community
- Docker y Docker Compose
- Ollama (opcional)

## Infraestructura

- Kali Linux: desarrollo, integración y ejecución.
- DigitalOcean: proxy inverso y acceso HTTPS.
